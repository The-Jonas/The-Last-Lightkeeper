What is in a file o que cada linha guarda

One file = one run of the game. One line = one JSON object. A run that crashes stays readable: only the last line is lost. Three kinds of line, told apart by k:

kWhenWhat it carries
metafirst linetester, build hash, start time, platform
sampleonce a second — four times a second while the monster chases or sanity is under 40 (hot says which)level, both brothers' position and sanity, who is controlled, party mode, light on and fuel, items carried, distance walked, monster state and distance, FPS and worst frame
eventwhen it happensthe type below, plus x/y and level where they make sense

Every line carries t: seconds since the game started.

EventMeans
envmachine and settings: renderer, resolution, cores, RAM, volumes, brightness
menu · state_pushwhat they picked in the main menu; every screen change
level_start · level_endfloor entered and left, with time, distance walked and seconds with the light on
death · victory · checkpoint_restarthow the run ended, where, and by what (monster or darkness)
monster_state · monster_flapevery state change of the monster, with the distance to the player. A state that bounces back and forth in under 0.4 s is not written one by one: it becomes a single monster_flap with the pair and the count — the line is itself the symptom of a defect
monster_hita touch: who took it, whether they were lit, how much sanity it cost and what was left
sanity_drop · sanity_tiera fall of 20 or more inside about a second (with the monster state and the light), and each crossing below 75, 50 and 25
idletwenty seconds without leaving the same 48 px: the player does not know what to do
stuckthe player held a direction for 2 s and the body did not move — a place where the map traps people
item_pickup · item_blockedwhat was taken, and what they tried to take with a full bag
candle_lit · candle_blown · window_closed · window_opened · repair_done · radio_usedthe world changing: the player lighting and closing, the monster opening
hide_start · hide_endthe closet, with how long they stayed in it
journal_open · journal_closewhich document, and how long it stayed on screen
tutorialwhich hint the game had to show — one that fires for everybody means the game does not explain itself
swap_brother · pause_menu · quit_confirmcontrol habits, and whether they really meant to leave
hitcha frame over 200 ms: a freeze the player can see
session_endclean exit, with the total duration and how it ended: window_close, quit_menu, quit_stage
crashthe session ended in a crash — written from inside the crash handler, so a crashed run no longer looks like an abandoned one

Events every discrete thing that happened
